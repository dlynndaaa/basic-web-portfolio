A fundamental, static personal web portfolio developed to showcase my academic background, technical skills, and organizational experiences. 

This project was built exclusively as the final submission for the **"Belajar Dasar Pemrograman Web"** (Basic Web Programming) certification course at **Dicoding Indonesia**. It serves as a foundational milestone, demonstrating core front-end concepts (Vanilla HTML, CSS, and JavaScript) before my transition to more advanced modern tech stacks for my upcoming main portfolio.

## 🚀 Key Features Demonstrated
- **Semantic HTML5:** Proper use of fundamental structural tags (`<header>`, `<main>`, `<section>`, `<footer>`) to build a well-organized document tree.
- **CSS Layouting:** Implementation of **CSS Flexbox** for styling, positioning, and content grid alignments without relying on external UI frameworks.
- **Vanilla JavaScript:** Basic DOM manipulation using `script.js` to handle interactive UI elements.
- **Responsive Web Design:** Implementation of CSS Media Queries to adapt the layout seamlessly across desktop, tablet, and mobile screens.
